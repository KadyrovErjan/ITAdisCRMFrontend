# ITadis CRM Frontend - Структура проекта

## 📁 Структура файлов

```

│   │   ├── Card.jsx        # Карточка
│   │   ├── Table.jsx       # Таблица
│   │   ├── Modal.jsx       # Модальное окно
│   │   ├── Button.jsx      # Кнопка
│   │   ├── Input.jsx       # Поле ввода
│   │   └── Loading.jsx     # Индикатор загрузки
│   │
│   ├── pages/              # Страницы приложения
│   │   ├── Login.jsx       # Страница входа
│   │   ├── Dashboard.jsx   # Главная панель
│   │   ├── Groups.jsx      # Управление группами
│   │   ├── Students.jsx    # Управление учениками
│   │   ├── Transactions.jsx # История транзакций
│   │   ├── Balances.jsx    # Балансы сотрудников
│   │   ├── Collections.jsx  # Сборы денег
│   │   ├── Expenses.jsx    # Расходы
│   │   ├── Analytics.jsx   # Аналитика (director)
│   │   ├── Users.jsx       # Управление пользователями (admin)
│   │   └── Profile.jsx     # Профиль пользователя
│   │
│   ├── services/           # API сервисы
│   │   └── api.js         # Axios конфигурация и все API методы
│   │
│   ├── store/             # State management (Zustand)
│   │   └── authStore.js   # Store для аутентификации
│   │
│   ├── utils/             # Утилиты
│   │   ├── format.js      # Форматирование (дата, валюта, роли)
│   │   └── validation.js  # Валидация форм
│   │
│   ├── hooks/             # Custom React hooks
│   │   └── useAuth.js     # Hook для аутентификации
│   │
│   ├── App.jsx            # Главный компонент с роутингом
│   ├── main.jsx           # Точка входа
│   └── index.css          # Глобальные стили (Tailwind)
│
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
└── postcss.config.js
```

## 🎨 Технологии

- **React 18** - UI библиотека
- **React Router v6** - Маршрутизация
- **Zustand** - State management (легче Redux)
- **Axios** - HTTP клиент
- **React Query** - Кеширование и управление серверными данными
- **React Hook Form** - Управление формами
- **Tailwind CSS** - Стили
- **Lucide React** - Иконки
- **React Hot Toast** - Уведомления
- **Recharts** - Графики для аналитики
- **date-fns** - Работа с датами
- **Vite** - Сборщик

## 🔐 Роли и доступ

### Cashier (Кассир)
- ✅ Создание и редактирование своих групп
- ✅ Регистрация учеников в свои группы
- ✅ Приём оплаты от учеников
- ✅ Просмотр своих транзакций
- ✅ Просмотр своего баланса

### Accountant (Бухгалтер)
- ✅ Просмотр всех групп, учеников, транзакций (read-only)
- ✅ Просмотр всех балансов
- ✅ Сбор денег у кассиров
- ✅ Фиксация расходов (со своего баланса)

### Director (Директор)
- ✅ Всё что у бухгалтера
- ✅ Сбор денег у кассиров и бухгалтера
- ✅ Редактирование всех групп
- ✅ Полная аналитика с графиками
- ✅ Экспорт отчётов в Excel

### Admin (Администратор)
- ✅ Создание/редактирование пользователей
- ✅ Назначение ролей
- ✅ Просмотр журнала аудита

## 📱 Страницы

### 1. Login (/)
- Форма входа (логин + пароль)
- JWT аутентификация
- Редирект по ролям

### 2. Dashboard (/dashboard)
- Статистика по роли пользователя
- Кассир: свой баланс, кол-во учеников, последние транзакции
- Бухгалтер/Директор: общие суммы, графики
- Быстрые действия

### 3. Groups (/groups)
- Список всех групп
- Создание группы (кассир)
- Обновление прогресса занятий
- Просмотр учеников группы
- Фильтры по предмету, кассиру

### 4. Students (/students)
- Список всех учеников
- Регистрация ученика с первым платежом (кассир)
- Приём доплаты (кассир)
- Просмотр истории оплат
- Фильтры по группе

### 5. Transactions (/transactions)
- История всех транзакций
- Кассир видит только свои
- Фильтры: даты, тип, группа, ученик
- Поиск по имени ученика

### 6. Balances (/balances)
- Свой баланс (все)
- Балансы всех сотрудников (бухгалтер/директор/админ)
- История изменений

### 7. Collections (/collections)
- Сбор денег у кассиров
- История сборов
- Фильтры по датам и пользователям

### 8. Expenses (/expenses)
- Фиксация расходов
- История расходов
- Обязательный комментарий
- Фильтры по датам

### 9. Analytics (/analytics) - только Director
- Общая сводка (доход/расход/прибыль)
- Помесячная разбивка с графиками
- Топ кассиров по сборам
- Расходы по пользователям
- Статистика по группам
- Экспорт в Excel

### 10. Users (/users) - только Admin
- Список пользователей
- Создание нового сотрудника
- Изменение роли
- Деактивация/активация

### 11. Profile (/profile)
- Информация о пользователе
- Смена пароля
- Настройки

## 🎨 UI/UX особенности

- **Адаптивный дизайн** - работает на мобильных устройствах
- **Темная/светлая тема** - переключение
- **Кыргызский язык** - основной интерфейс
- **Валидация форм** - в реальном времени
- **Toast уведомления** - успех/ошибка
- **Loading состояния** - для всех запросов
- **Error boundaries** - обработка ошибок
- **Кеширование данных** - React Query
- **Optimistic updates** - мгновенный UI feedback

## 🔗 API Integration

Все запросы идут через proxy на `http://localhost:8000/api/v1/`

- JWT токены хранятся в localStorage
- Автоматическое обновление access token при истечении
- Автоматический logout при 401
- Обработка всех ошибок API

## 📊 Графики (Recharts)

- Line Chart - динамика доходов/расходов
- Bar Chart - сравнение месяцев
- Pie Chart - распределение расходов
- Area Chart - накопленная прибыль
